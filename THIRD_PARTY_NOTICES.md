# Third-party components

Sound Pocket bundles Python, Flask, Waitress, yt-dlp and dependencies, pywebview,
pythonnet, Node.js, and the FFmpeg executable distributed by imageio-ffmpeg.
License texts available in the installed distributions are included in this folder.

- Python: https://www.python.org/ — PSF license
- Node.js: https://nodejs.org/ — MIT and bundled third-party licenses
- yt-dlp: https://github.com/yt-dlp/yt-dlp — Unlicense; dependencies have separate licenses
- pywebview: https://github.com/r0x0r/pywebview — BSD-3-Clause
- imageio-ffmpeg: https://github.com/imageio/imageio-ffmpeg — BSD-2-Clause wrapper
- FFmpeg: https://ffmpeg.org/ — this Windows binary is a GPL-enabled build from
  https://www.gyan.dev/ffmpeg/builds/ (7.1 essentials, distributed by imageio-ffmpeg 0.6.0).
  Build scripts and source references: https://github.com/imageio/imageio-ffmpeg/tree/v0.6.0

Microsoft Edge WebView2 Runtime is a separate Microsoft component installed on the PC.
