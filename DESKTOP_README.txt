Sound Pocket — Windows PC용 MP3 변환 앱

1. SoundPocket-Windows-x64.zip 전체를 원하는 폴더에 압축 해제하세요.
2. SoundPocket 폴더의 SoundPocket.exe를 더블 클릭하세요.
3. YouTube 영상 주소를 입력하고 MP3로 변환하기를 누르세요.
4. 완료 후 MP3 다운로드를 누르고 저장할 위치를 선택하세요.

SoundPocket.exe와 _internal 폴더를 함께 두어야 합니다.
Python, Node.js, FFmpeg를 따로 설치할 필요가 없습니다.
Windows 10/11 64비트와 Microsoft Edge WebView2 Runtime이 필요합니다.
WebView2가 없다면 Microsoft 공식 설치 페이지를 이용하세요:
https://developer.microsoft.com/microsoft-edge/webview2/

각자의 PC와 인터넷으로 다운로드 및 변환합니다.
Render 또는 다른 변환 서버로 영상이나 MP3를 보내지 않습니다.
인터넷 연결이 필요하며, 앱을 닫으면 진행 중 작업은 취소됩니다.
최대 30분 영상, 한 번에 한 개, 128/192kbps를 지원합니다.
임시 MP3는 15분 뒤 또는 앱 종료 시 삭제됩니다. 저장한 MP3는 삭제하지 않습니다.
정상 종료 시 임시 작업 폴더를 정리합니다. 강제 종료하면 임시 파일이 남을 수 있습니다.
실행 로그 및 임시 데이터 위치: %LOCALAPPDATA%\SoundPocket

이 앱은 코드 서명되지 않았으므로 Windows에서 게시자를 확인할 수 없다고 표시할 수 있습니다.
받은 파일의 출처를 확인하세요. 보안 프로그램을 끄지 마세요.
YouTube 정책/접근 제한에 따라 실패할 수 있으며 차단 해제를 보장하지 않습니다.
직접 제작했거나 다운로드·변환 권한이 있는 영상에 사용하세요.

다른 사람에게 전달할 때 ZIP 파일 전체를 공유하세요. 각자 압축 해제하고 실행하면 됩니다.
macOS와 Linux용 실행 파일은 이 ZIP에 포함되어 있지 않습니다.
